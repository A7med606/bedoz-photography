## نظرة عامة

**BeDoz Photography** هو تطبيق ويب تقدمي (PWA) متكامل لإدارة وحجز جلسات التصوير الاحترافي. صُمّم خصيصاً للمصورين المحترفين في مصر، يوفر منصة كاملة للعملاء للتصفح والحجز مباشرة من الهاتف أو الكمبيوتر.

الميزة الأكبر: **يعمل بدون سيرفر!** جميع البيانات محفوظة في المتصفح (localStorage)، مما يجعله مناسباً للنشر على أي استضافة مجانية مثل GitHub Pages.

## المميزات الرئيسية

### للعملاء
- **📱 تصميم متجاوب** - يعمل بشكل مثالي على جميع الأجهزة
- **🎨 معرض الأعمال** - تصفح أعمال التصوير بتصميم جذاب
- **📦 عرض الباقات** - 4 باقات باسعار مختلفة مع تفاصيل كاملة
- **📅 حجز جلسات** - تقويم تفاعلي لاختيار التاريخ والوقت
- **🤖 مساعد ذكي** - شات بوت يرد على الاستفسارات بالعربية
- **📱 واتساب** - إرسال تفاصيل الحجز مباشرة على واتساب
- **⚡ وضع عدم الاتصال** - يعمل بدون إنترنت بفضل Service Worker

### للمدير
- **🔐 لوحة تحكم آمنة** - كلمة مرور محمية
- **📦 إدارة الباقات** - تعديل الاسعار والمميزات
- **📋 إدارة الحجزات** - عرض وتأكيد وحذف الحجزات
- **🚫 التواريخ المحظورة** - حظر ايام معينة
- **⚙️ الإعدادات** - رقم واتساب للتواصل
- **💾 نسخ احتياطي** - تصدير واستيراد البيانات
- **🔔 اشعارات** - شارة اشعارات على الحجزات الجديدة

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| **HTML5 / CSS3 / JavaScript** | البناء الاساسي للتطبيق |
| **PWA** | تطبيق ويب تقدمي مع وضع عدم الاتصال |
| **Service Worker** | التخزين المؤقت والعمل بدون إنترنت |
| **localStorage** | حفظ البيانات محلياً في المتصفح |
| **IntersectionObserver** | تأثيرات الحركة عند التمرير |
| **CSS Animations** | تأثيرات بصرية متقدمة |
| **Node.js / Express** | سيرفر خلفي (اختياري) |
| **MongoDB** | قاعدة بيانات (اختياري) |

## هيكل المشروع

```
bedoz-photography/
├── index.html          # الصفحة الرئيسية (SPA كاملة)
├── sw.js               # Service Worker للعمل بدون إنترنت
├── manifest.json       # ملف PWA
├── public/             # نسخة الاستضافة
│   ├── index.html
│   ├── sw.js
│   └── manifest.json
├── server.js           # سيرفر Express (اختياري)
├── package.json        # تبعيات Node.js
├── presentation.html   # العرض التقديمي
└── DEPLOYMENT.md       # دليل النشر التفصيلي
```

## التشغيل المحلي

###选项 1: بدون سيرفر (مباشر)
```bash
#افتح index.html مباشرة في المتصفح
start index.html
```

###选项 2: مع سيرفر Node.js
```bash
# تثبيت التبعيات
npm install

# تشغيل السيرفر
npm start

# الفتح في المتصفح
# http://localhost:3000
```

---

## النشر على GitHub Pages

1. ارفع الملفات `index.html` و `sw.js` و `manifest.json` للمستودع
2. اذهب到 **Settings > Pages**
3. اختر **Source: Deploy from a branch**
4. اختر **Branch: main**
5. اضغط **Save**

الرابط سيكون: `https://username.github.io/repo-name/`

## المميزات التقنية

### التصميم
- **داكن احترافي** - خلفية #0a0e13 مع لمسات سماوية #00e5ff
- **RTL كامل** - دعم كامل للعربية من اليمين لليسار
- **متجاوب** - يعمل على الموبايل والتابلت والكمبيوتر
- **أنيميشن متقدمة** - تأثيرات hover و scroll و pulse

### الأداء
- **PWA كامل** - يمكن تثبيته على الهاتف
- **Service Worker** - التخزين المؤقت وسرعة التحميل
- **عمل بدون إنترنت** - يعمل حتى بدون اتصال
- **ملف واحد** - HTML + CSS + JS في ملف واحد (~80KB)

### الأمان
- **حماية لوحة التحكم** - كلمة مرور للدخول
- **بيانات محلية** - لا يتم إرسال بيانات لسيرفر خارجي
- **لا ملفات مُلزمة** - لا حاجة لـ .env في وضع GitHub Pages
